# UI guidelines

- Lead with the operational outcome and current state.
- Keep the primary navigation ordered: Overview, Agents, Fleets, Policies, Budgets, Audit Center,
  Emergency, AI Assessment Lab.
- Use tables for comparable governance records and status badges for lifecycle state.
- Require confirmation for destructive or emergency actions.
- Preserve server error messages when safe and provide retry actions for transient failures.
- Keep filters labeled and keyboard accessible; placeholders are examples, not labels.
- Announce loading and status changes to assistive technology.
- Never display generated sample metrics as live operational data.
- Keep the Assessment Lab visually connected but clearly separated from financial enforcement.
