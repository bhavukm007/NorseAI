# Presentation outline

1. **Problem** — autonomous financial agents need enforceable, evidence-producing controls.
2. **Solution** — one mandatory gateway for status, policy, budget, execution, and audit.
3. **Architecture** — authenticated React workspace, layered FastAPI services, PostgreSQL,
   sandbox adapter, immutable evidence.
4. **Financial Agent** — organization, fleet, agent, policy assignment.
5. **Governance Decision** — deterministic precedence and default denial.
6. **Budget Enforcement** — agent, fleet, and organization reservations.
7. **Emergency Stop** — immediate fleet-wide execution block.
8. **Audit Trail** — trace and export the complete decision.
9. **AI Assessment Lab** — demonstrate broader AI risk governance.
10. **Production readiness** — revocable sessions, security headers, rate limits, migrations,
    tests, scans, containers, and CI.
11. **Impact and boundary** — practical control plane today; sandbox execution and documented
    extension points.
