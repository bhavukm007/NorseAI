# Roadmap

## Completed

- Phase 01 — deployable FastAPI/React foundation
- Phase 02 — governance engine, RBAC, spend controls, and immutable audit
- Phase 03 — responsive operator dashboard foundation
- Phase 04 — deterministic AI Assessment Lab and report exports
- Phase 05 — accessibility, resilience, and hackathon demonstration polish
- Phase 06 — financial governance gateway, fleets, hierarchical budgets, and reversals
- Phase 07 — authenticated Operator Governance Platform
- Phase 08 — authentication, security, audit, dependency, configuration, and CI hardening
- Phase 09 — documentation, cleanup, and final submission readiness

## Post-submission opportunities

- Replace process-local throttling with a shared Redis limiter for multi-instance deployments.
- Integrate signed OPA policy bundles while retaining deterministic decision evidence.
- Connect a real payment-provider adapter behind the existing governed execution interface.
- Persist Assessment Lab workspaces and evidence attachments by organization.
- Add signed report attestations, scheduled reassessment, and regulation-specific control packs.
- Add metrics, tracing, alerting, backup/restore exercises, and operational runbooks.

These are future opportunities and are not represented as current functionality.
